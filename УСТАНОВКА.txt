  ETALONCENTER — Инструкция установки на REG.RU
══════════════════════════════════════════════════════

ШАГ 1 — СОЗДАЙТЕ БАЗУ ДАННЫХ
─────────────────────────────
1. Войдите в панель REG.RU
2. Раздел «Базы данных MySQL» → «Создать базу данных»
3. Запомните: имя БД, пользователь, пароль

ШАГ 2 — ЗАГРУЗИТЕ БД (ДВА ФАЙЛА, ПО ПОРЯДКУ)
──────────────────────────────────────────────
1. Откройте phpMyAdmin (в разделе «Базы данных»)
2. Выберите вашу БД слева
3. Вкладка «Импорт» → загрузите СНАЧАЛА db/schema.sql (структура), «Выполнить»
4. Затем так же импортируйте db/seed.sql (данные), «Выполнить»
   • Раздел 1 файла seed.sql (справочники, филиал, станки) нужен всегда.
   • Раздел 2 — тестовые данные (тренеры, услуги, тренировки, демо-админ);
     на «боевом» сайте можно не грузить или отредактировать под себя.

ШАГ 3 — НАСТРОЙТЕ ПОДКЛЮЧЕНИЕ К БД
────────────────────────────────────
Откройте файл: config/db.php
Заполните строки:

  define('DB_NAME', 'имя_вашей_бд');
  define('DB_USER', 'пользователь_бд');
  define('DB_PASS', 'пароль_бд');
  define('JWT_SECRET', 'любая-случайная-строка-32-символа');
  define('SITE_URL', 'https://ваш-домен.ru');

ШАГ 4 — ЗАГРУЗИТЕ ВСЕ ФАЙЛЫ
──────────────────────────────
Через Файловый менеджер REG.RU перейдите в папку public_html
и загрузите ВСЁ содержимое этого архива:

  public_html/
    index.html      ← главный файл сайта
    .htaccess       ← настройки сервера
    db/             ← schema.sql + seed.sql (импортируются в БД, см. ШАГ 2)
    api/            ← папка с PHP-файлами API
    config/         ← настройки БД
    middleware/     ← вспомогательные функции
    assets/         ← логотип, фавиконка
    css/            ← стили

ШАГ 5 — ПРОВЕРЬТЕ САЙТ
────────────────────────
Откройте ваш домен в браузере.
Войдите как администратор (демо-учётка из seed.sql, раздел 2):
  Email:  admin@local
  Пароль: admin123

⚠️  СРАЗУ СМЕНИТЕ ПАРОЛЬ АДМИНИСТРАТОРА!
